1. 核心架構與非同步平行處理（Web Worker Architecture）
由於幣安 USDT 永續合約（USDT-Margined Perpetual Futures）涵蓋了數百個交易對，若在瀏覽器的主執行緒（Main Thread）中同步發送 API 請求並計算技術指標，會造成嚴重的 UI 卡頓。
 * 背景運算分離：系統將資料抓取與運算邏輯打包至 Web Worker 中執行。主執行緒僅負責發送啟動指令與接收最終結構化的數據。
 * 批次請求與限速管理：Worker 透過 fetch 串接幣安期貨公開 API（如 /fapi/v1/exchangeInfo 獲取交易對清單，/fapi/v1/klines 取得歷史 K 線），並採用分批非同步請求（Promise.all / 控管並發數），避免觸發幣安 API 的 Rate Limit（頻率限制）。
2. 多週期均線與多頭排列演算法（Bullish Alignment Logic）
儀表板的核心靈魂在於對多個時間維度（如 15M、1H、4H、1D）進行矩陣式的趨勢掃描。
 * 均線定義：系統計算多條經典簡單移動平均線（SMA），常見如 5MA、30MA、45MA、60MA，以及成交量均線（5VM、20VM）。

3. 多維度選股與低風險篩選策略（Screening Strategies）
除了常規的單一週期篩選外，程式內建了進階的交易策略邏輯：
 * 剛突破（Breakout）判定：透過檢測最新一根 K 線與前一根 K 線的狀態，判斷均線是否在近期發生黃金交叉，或價格帶量突破 4H 的關鍵阻力位。
 * 拉回貼近（Pullback）策略：尋找「大週期（如 4H）處於強勢多頭排列」，但「小週期（如 1H）正處於向均線回測（Pullback）」的標的。這類邏輯能自動過濾掉追高風險，精準挑選出風險報酬比更佳的切入點。
4. 高效能自訂 Canvas 圖表繪製引擎（Custom Canvas Rendering）
為了確保在動態切換多個幣種時圖表能達到 60 FPS 的流暢度，系統捨棄了沈重的 DOM-based 圖表庫，採用原生 HTML5 Canvas 實作微型繪圖引擎。
 * 座標映射（Coordinate Mapping）：
   系統會根據當前畫面的寬高與可視 K 線數量，動態計算價格極值（High / Low）與像素座標的轉換比例（Scale），確保漲跌幅能精準成比例縮放。
 * 圖層分流繪製：
   * 背景與網格層：繪製價格坐標軸、時間格線與零軸。
   * K 線與成交量層：根據開高低收（OHLC）動態繪製實體柱與上下影線（紅綠分明），下方同步渲染對應的成交量柱狀圖與量均線。
   * 技術指標線層：將計算好的多條 MA 線以平滑路徑（Path）疊加繪製於主圖上。
   * 訊號標記層：在符合特定突破或共振條件的 K 線上方渲染專屬圖示（如 ⚡、🔥）。
5. UI 互動與響應式狀態管理（Interaction & State Management）
 * 多端適配（Responsive Design）：介面支援桌面端與行動端瀏覽。在手機端透過監聽 touchstart 與 touchend 事件支援左右滑動切換不同幣種的圖表；桌面端則支援鍵盤左右方向鍵（ArrowLeft, ArrowRight）快速切換觀察清單。
 * 即時狀態同步：當篩選條件（如切換 1H 變 4H、或調整排序依據）改變時，狀態管理器會立即觸發局部重算與 Canvas 重繪，確保交易員在瞬息萬變的加密貨幣市場中能以最高效率執行多維度交叉比對。
